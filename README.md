# Платформа цифрового двійника насосної станції

Лабораторна робота 1 з дисципліни «Архітектури імерсивних систем та платформ цифрових двійників»: архітектурний опис і модель платформи цифрового двійника.

## Об’єкт

**Насосна станція підвищення тиску (НСПТ) житлового кварталу.** Станція забирає воду з міської магістралі (1,5–2,5 бар) і подає її в мережу кварталу з тиском ≈ 5 бар. Два насоси (робочий і резервний), ПЛК із частотними перетворювачами, 16 сигналів телеметрії.

Платформа — **цифровий двійник** (двобічний зв’язок): показує стан станції в реальному часі (дашборд і 3D-сцена), формує тривоги, оцінює енергоефективність і знос підшипників, дає змогу дистанційно змінювати уставку тиску, режим і пускати / зупиняти насоси. Регулювання й захисти залишаються в ПЛК станції.

## Мова моделі

**SysML v2** (текстова нотація), середовище — **SysML v2 Pilot Implementation** (ядро SysML для JupyterLab).

## Як переглянути модель

- **Без встановлення:** відкрити `model/export/model.html` у браузері — модель і всі діаграми.
- **У JupyterLab:** встановити SysML v2 Pilot (Java 21+, Miniconda, `install.sh` / `install.bat` з релізу SysML-v2-Release), запустити `jupyter lab`, відкрити `model/model.ipynb` і виконати **Kernel → Restart Kernel and Run All Cells**.

Модель складається з чотирьох пакетів: вимоги за доменами ISO 23247, структура (блоки й з’єднання), поведінка (обробка відліку телеметрії) і трасовність (`satisfy` / `verify`).
